# 누벨라 마이페이지 구현 전달 문서

아래 내용을 새 프로젝트의 에이전트에게 그대로 전달하면 동일하게 구현할 수 있습니다.

---

## 기술 스택

- React 18 + TypeScript
- Wouter (라우팅)
- TanStack Query (서버 상태 관리)
- Tailwind CSS (스타일링)
- shadcn/ui (UI 컴포넌트: Button, Input, Label, Dialog, Tabs, Card 등)
- Lucide React (아이콘)
- Express.js (백엔드 API)
- PostgreSQL + Drizzle ORM (데이터베이스)
- 인증: localStorage에 memberToken 저장 방식 (Bearer 토큰)

---

## 페이지 구성 및 라우팅


## useMemberInfo Hook

```typescript
// client/src/hooks/useMemberInfo.ts
import { useQuery, useQueryClient } from "@tanstack/react-query";

export interface MemberInfo {
  id: string;
  username: string;
  name: string;
  nickname: string | null;
  email: string | null;
  phone: string | null;
  pointBalance: number;
  isFrozen: boolean;
  createdAt: string;
}

export function useMemberInfo() {
  const memberToken = localStorage.getItem("memberToken");
  const isLoggedIn = !!memberToken;

  const query = useQuery<MemberInfo>({
    queryKey: ["member-info"],
    queryFn: async () => {
      const res = await fetch("/api/members/me", {
        headers: { Authorization: `Bearer ${memberToken}` },
      });
      const data = await res.json();
      if (!data.success) throw new Error(data.error);
      return data.data;
    },
    enabled: isLoggedIn,
    staleTime: 0,
    refetchOnMount: true,
    refetchOnWindowFocus: true,
  });

  return { ...query, isLoggedIn, memberToken };
}
```

## 백엔드 API 목록

### 회원 관련
```
GET  /api/members/me                  → 내 정보 조회 (Authorization: Bearer {token})
DELETE /api/members/me               → 회원 탈퇴
PATCH /api/members/me                → 정보 수정 (name, nickname, phone, password 등)
POST /api/members/signup             → 회원가입 { username, password, name, nickname, phone, email }
POST /api/members/login              → 로그인 { username, password } → { token, memberId, memberName, ... }
```

### 포인트/입출금
```
GET  /api/members/deposit-requests   → 내 입금신청 목록
POST /api/members/deposit-requests   → 입금신청 { amount, bankName, depositorName }
GET  /api/members/withdrawal-requests → 내 환급신청 목록
POST /api/members/withdrawal-requests → 환급신청 { amount }
GET  /api/members/point-transactions → 내 포인트 거래내역
```

### 주문
```
GET  /api/members/orders             → 내 주문 목록 (?memberId=xxx)
POST /api/orders                     → 주문 생성
PATCH /api/orders/:id/address        → 배송지 수정
PATCH /api/orders/:id/shipping       → 배송 정보 수정
POST /api/orders/:id/cancel          → 주문 취소 (포인트 환불 포함)
GET  /api/members/recent-addresses   → 최근 배송지 목록
```

### 리뷰
```
GET  /api/reviews                    → 전체 리뷰 목록
POST /api/reviews                    → 리뷰 작성 { productId, orderId, rating, content, authorName }
  ※ content 최소 50자 필수
```

### FAQ/설정
```
GET  /api/faqs                       → FAQ 목록
GET  /api/settings/kakaoTalkLink     → 카카오톡 링크 설정값
```

## 마이페이지 (Profile.tsx) 탭 구성

### 상단 헤더
- 금색(amber) 그라데이션 배경
- 로그인 여부에 따라 회원 이름/이메일 표시 또는 로그인 유도

### 요약 카드 3개 (최상단)
- 장바구니 (찜 목록 개수)
- 찜 목록
- 포인트 잔액 → /deposit 이동

### 탭 구성 (6개)
1. **내 정보** - 이름, 닉네임, 전화번호, 이메일, 비밀번호 변경, 계정 동결 표시
2. **주문내역** - 주문 상태별 목록, 리뷰 작성 버튼, 배송지 수정, 주문 취소
3. **포인트** - 잔액 표시, 입금신청 폼, 환급신청 폼, 거래내역
4. **입금내역** - 입금신청 상태 (pending/approved/rejected)
5. **환급내역** - 환급신청 상태
6. **찜 목록** - localStorage 기반 위시리스트

### 주문 상태 표시
- pending → "주문접수"
- processing → "처리중"  
- confirmed → "주문확인"
- shipped → "배송중"
- delivered → "배송완료"
- cancelled → "취소됨"

## 포인트 관리 (Deposit.tsx) 탭 구성

1. **포인트 충전** - 카카오톡 고객센터 링크 + 입금신청 폼 (금액, 입금자명)
2. **포인트 환급** - 환급 안내 + 환급신청 폼 (금액만 입력, 최소 10,000원)
3. **지급 내역** - 전체 포인트 거래내역 (type별 색상 구분)

포인트 잔액 상단 표시 (amber 그라데이션, 5초마다 자동 갱신)

## 참고: 인증 방식

로그인 성공 시 서버가 토큰 반환 → localStorage 저장 → 이후 모든 API 요청 헤더에 포함

```javascript
headers: {
  "Authorization": `Bearer ${localStorage.getItem("memberToken")}`
}
```

토큰 유효성 검사는 서버에서 DB의 `member_sessions` 또는 `admin_sessions` 테이블로 관리
